# Security

Please report security issues privately via
[GitHub's private vulnerability reporting](https://github.com/paulogenargue/landrop/security/advisories/new),
not in a public issue. I'll reply as soon as I can.

Known, documented trade-offs (plain HTTP on the LAN, anyone with the token can
read the clipboard and fill the disk) are covered in the README's Security
section and aren't vulnerabilities by themselves.
